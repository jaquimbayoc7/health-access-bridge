Cómo se hicieron. Con Archify (licencia MIT): cada diagrama se describe en JSON (carpeta fuentes/) y construir.mjs lo valida y genera un HTML autosuficiente con animación de trazas, que se abre sin instalar nada. Los videos de esta página (video/) son grabaciones de 14 s de esas animaciones para usar en presentaciones. Todos los datos son sintéticos; no hay información de pacientes.
